# 2026-04-23 Daily Log

## 修复：Daily船期修改speed值后跳回原值

**问题**：用户在Daily船期页面修改speed值后，值会跳回到原来的值。

**原因**：`recalcDailyFromPort` 函数在重算后续港口日期时，如果发现下一港已有ETA，会反推speed值（第8318行），覆盖用户刚输入的值。

**修复**：
1. `recalcDailyFromPort` 添加第四个参数 `skipSpeedBackfill`（默认false）
2. 当编辑speed字段时，调用 `recalcDailyFromPort(vessel, voyIdx, portIdx + 1, true)` 跳过speed反推
3. 其他场景（如dist编辑、ETA编辑等）仍然会正确反推speed

**位置**：shipping_schedule.html 第8279行（函数定义）、第8101行（speed编辑调用）

## 修复：修改speed后时间没有跟着变

**问题**：用户在Daily船期页面修改speed后，后续港口时间没有重新计算。

**原因**：`recalcDailyFromPort` 碰到后续港口已有ETA时，会优先用旧ETA反推而不是用新speed正向计算。

**修复**：编辑speed字段时，先清除后续所有港口的ETA/ETB/ETD，再调用重算强制正向推演。
